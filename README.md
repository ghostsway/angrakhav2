## Getting Started

1. Clone the repository: `git clone https://github.com/ghostsway/angrakhav2.git`
2. Install dependencies: `npm install`
3. Deploy to Railway: `railway deploy --token=your-railway-token --env=MONGO_URI=mongodb://mongo:tWuvEOxfwTMxWStSFPcqNkweDWiFkxhO@mongodb.railway.internal:27017`
4. Deploy to Vercel: `vercel deploy --github-token=your-vercel-token --env=REACT_APP_BACKEND_URL=https://your-backend-url.com`

## Development

* Run `npm start` to start the development server.
